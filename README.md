# Hausla

**Courage for every step.** A free, India-first companion for people affected by
cancer: clear guides, verified care and financial help, and places to find support.

> Hausla shares information to help people understand cancer and navigate care. It is
> not medical advice.

- Live (in development): https://pponetwothree.github.io/hausla/
- Design system: https://pponetwothree.github.io/hausla/style-tile/
- Plan: [ROADMAP.md](ROADMAP.md) · Project decisions: [CLAUDE.md](CLAUDE.md)

## Develop

```bash
npm install
npm run dev      # http://localhost:4321/hausla/
npm run build    # static site in dist/
```
